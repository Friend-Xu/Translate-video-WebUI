# =============================================================================
# CosyVoice TTS — Isolated Environment (NOT installed in main .venv)
# =============================================================================
# CosyVoice runs in a SEPARATE Python 3.10 subprocess to avoid PyTorch version
# conflicts with the main environment (ChatTTS needs PyTorch 2.6, CosyVoice
# needs PyTorch 2.3.1 with specific CUDA builds).
#
# Architecture:
#   Main .venv/                   ← this file (pipeline/tts_cosyvoice.py)
#       │ subprocess.Popen()
#       ▼
#   models/CosyVoice/.python310/  ← isolated Python 3.10 runtime
#   models/CosyVoice/.cosyvenv/   ← isolated site-packages
#       │
#       ▼
#   models/CosyVoice/cosyvoice_worker.py  ← stdin/stdout JSON protocol
#
# The isolated environment has its OWN requirements at:
#   models/CosyVoice/requirements.txt
#
# Key dependencies in the isolated env (NOT needed in main .venv):
#   torch==2.3.1, transformers==4.51.3, modelscope, onnxruntime, wetext, etc.
#
# The main environment only needs torch + torchaudio (declared above) for
# prompt audio preprocessing (load/resample → 16kHz mono WAV for the worker).
#
# To set up the isolated environment:
#   1. Download portable Python 3.10 → models/CosyVoice/.python310/
#   2. Create venv: .python310/python.exe -m venv .cosyvenv
#   3. pip install -r models/CosyVoice/requirements.txt (in .cosyvenv)
#   4. Download CosyVoice2-0.5B model → models/CosyVoice2-0.5B/
# =============================================================================
