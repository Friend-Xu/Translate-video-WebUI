**旁白**:
> 回到主界面。选择你要翻译的视频。语言这里选英文，模型用 turbo，设备选 GPU。下面的字幕提取、翻译、TTS 合成三个步骤，全部保持开启。这就是全自动模式。

## 4. 工作流二: 字幕审校模式 (2:15-3:40)

### 4a. 开启审校 (2:15-2:40)

**画面**: 回到主界面 -> 鼠标移动到"翻译完成后先校验"复选框 -> 高亮勾选 -> 再次确认三个步骤都开启

**旁白**:
> 一键模式很快，但机器翻译有时候会翻错，特别是专业术语和人名。如果你想更靠谱，就用第二种工作流：字幕审校模式。勾上"翻译完成后先校验"。其他设置不变，点开始。

**字幕**: 同旁白

### 4b. 翻译暂停 (2:40-3:00)

**画面**: 点击"开始处理" -> 进度条跑到约 60%（翻译阶段）后自动暂停 -> 界面上出现醒目的"开始字幕校验"按钮 -> 鼠标悬停在按钮上

**旁白**:
> 这次不一样了。当流水线跑完翻译步骤后，它会自动暂停，弹出一个"开始字幕校验"按钮。翻译结果等你确认之后，才会继续生成配音。

**字幕**: 同旁白

### 4c. 字幕审校 (3:00-3:25)

**画面**: 点击"开始字幕校验" -> 自动切到字幕校准标签页 -> 展示中英对照的字幕列表 -> 鼠标双击某条中文译文 -> 修改文字 -> 按 Enter 确认 -> 点击状态图标标为"已审校"

**旁白**:
> 点进去就到了字幕校准界面。左边是英文原文，右边是中文译文。你逐条看过去，有翻得不对的地方，双击就能直接改。改完按回车。审完的点一下标记，方便追踪进度。支持键盘快捷键，效率很高。

**字幕**: 同旁白

### 4d. 继续 TTS (3:25-3:40)

**画面**: 按 Ctrl+S 保存 -> 切回主界面 -> 出现"继续 TTS 合成"按钮 -> 点击 -> 流水线继续运行 -> 展示最终成品

**旁白**:
> 审校完 Ctrl+S 保存，回到主界面，点"继续 TTS 合成"。流水线会用你校对过的字幕来配音。这样生成的最终视频，翻译质量更有保障。

**字幕**: 同旁白
